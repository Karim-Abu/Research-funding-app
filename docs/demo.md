# Demo Guide (Portfolio-Oriented)

This project can be demonstrated locally without real provider credentials using demo data and fake providers.

## Recommended Demo Flow (8–12 minutes)

1. Log in with seeded demo user
2. Create or open a demo project
3. Import a sample source document
4. Start a run and observe stage progression
5. Open field drafts and inspect suggestions
6. Review findings and open issues
7. Export generated outputs

Reference specs for this flow:

- `e2e/golden-path.spec.ts`
- `e2e/import-functional.spec.ts`
- `e2e/review-truth.spec.ts`
