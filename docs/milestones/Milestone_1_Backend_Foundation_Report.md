## 4. Endpoints implemented (exact contract paths, `/api/v1`)

`POST/GET/DELETE /session`, `GET /me`, `GET /capabilities`, `GET /health`,
`GET/POST /projects`, `GET/PATCH /projects/{project_id}`.

- Server-side sessions (random id, HTTP-only cookie `SameSite=Lax`, `Secure` env-configurable, TTL +
  revocation). **CSRF = synchronizer token** stored in `UserSession`, returned by session responses,
  required as `X-CSRF-Token` on unsafe authenticated methods; **Origin validated** on those methods.
- **Idempotency:** `POST /projects` requires `Idempotency-Key` (persisted); same key+body ⇒ original
  resource, same key+different body ⇒ `409`.
- Workspace scoping on every project query; audit rows for login/logout/create/update; Problem Details
  (`application/problem+json`) for `401/403/404/409/422` with `correlation_id`.

## 8. Contract notes / ambiguities (resolved from `openapi-v1_1.yaml`)
- Error schema is named **`Problem`** (media type `application/problem+json`) — not "ProblemDetails";
  used the contract name.
- **`ProjectPatch`** intentionally has no `data_classification` (reclassification is a separate,
  out-of-scope endpoint) — honored.
- **`Health`** requires `policy_version` + `agent_registry_version`; sourced from the contract registry
  files (all `1.1.0`) via settings (deployment-config values).
- **`funding_instrument_profile_id`** = `innosuisse_innovation_project_with_implementation_partner`
  (resolved from `requirements.yaml` / profile registry).
- `Project.workflow_summary` is optional → `null` in Milestone 1.
- CSRF/Origin applied exactly where the contract attaches `X-CSRF-Token` (delete-session,
  create-project, patch-project); login authenticates by credentials (no CSRF param in the contract).

```
python -m venv .venv
.venv\Scripts\activate            # Windows (use source .venv/bin/activate on POSIX)
pip install -r requirements.txt
alembic upgrade head
python -m app.seed
uvicorn app.main:app --port 8000
```
Dev login: `anna.keller@example.test` / `changeme-dev-lead` (lead_admin) or

**Frontend** (repo root): create `.env.local` with
```
FASTAPI_BRIDGE_URL=http://127.0.0.1:8000/api/v1
APP_BACKEND_MODE=live        # omit or set "mock" to run fully on mocks
```
then `pnpm install` and `pnpm dev`. Tests: `pnpm test` (frontend), `pytest` in `backend/`.

## 10. Security
No `NEXT_PUBLIC_*` secrets; `FASTAPI_BRIDGE_URL` is read only server-side (`lib/bridge.ts`). HTTP-only
session cookie; CSRF synchronizer token held in browser memory only; argon2 hashes; structured logs
redact passwords/tokens; no self-sign-up. The implementation is left **uncommitted** for review.
