## Deterministic IDs

- Namespace: `0fef17a7-6de1-56c4-a53e-3d3e6ef7c611`
- Seed version: `demo-dataset-v1`

The demo manifest table records object ownership for project, partner, source,
source_version, run, operation, and storage references.
